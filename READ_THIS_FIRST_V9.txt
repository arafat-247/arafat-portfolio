ARAFAT PORTFOLIO V9 — EDITORIAL MONOGRAPH

V9 is a total visual reset. It does not reuse the V7/V8 homepage theme.

VISIBLE SITE STRUCTURE
Home · Archive · Photography · About · Contact

CORE V9 CHANGES
- Completely new light editorial-monograph theme.
- New typographic masthead. No A/R box logo.
- Full-screen mobile navigation instead of a dropdown panel.
- New portrait-led homepage with restrained identity treatment.
- Latest Work: one lead + four supporting stories, sorted by real publication timestamp.
- Archive uses the lightweight archive-index.json generated during deployment.
- Designed Contact / professional profile blocks.
- Designed Send a News Tip treatment.
- New About, Photography, Contact, Archive and 404 layouts.
- Story pages rebuilt from scratch: compact opening, published date, full original byline, story visual, clean article + contextual rail.
- Every verified story receives an original subject-led editorial SVG if no hand-curated hero image exists.
- Inline quote/data/timeline/map/table modules still work when added to story_enhancements.json.
- Real article tables become searchable/sortable and can be downloaded as CSV.
- Sticky share, Print/Save PDF, related stories and newer/older story navigation retained.
- SEO, structured data, RSS, sitemap, robots, accessibility and performance budget retained.
- Light theme only in V9; the old automatic dark presentation is removed.

UPLOAD — SITE
Upload/replace everything inside this package's site/ folder into your GitHub repository's site/ folder.
Do NOT manually create or upload:
- site/data/articles.json
- site/data/archive-index.json
- site/data/story_art_queue.json
They are generated by GitHub Actions.

UPLOAD — BACKEND
At repository root:
- requirements.txt

Inside scripts/:
- update_articles.py
- build_static.py
- optimise_images.py
- check_budget.py

Hidden workflow:
- .github/workflows/deploy.yml

If your phone hides .github, open the existing .github/workflows/deploy.yml in GitHub and replace its contents with V9_DEPLOY_YML_VISIBLE.txt.

PORTRAITS
V9 includes optimised supplied portraits in:
site/assets/portraits/

PHOTOGRAPHY
The photography page is ready but site/data/photography.json is intentionally empty until actual photographs are curated. It links to Flickr in the meantime.

AFTER UPLOAD
Commit all changes and wait for the newest GitHub Action to turn green. Do not start another workflow while it is running.
