# Quick publisher

Open this form on desktop or phone:

https://github.com/arafat-247/arafat-portfolio/issues/new?template=quick-publish.yml

Paste the finished article, add the deck and category, and optionally drag a cover image into the cover field. Choose **Publish now** or **Save as draft**.

The workflow updates `content/posts.json`, stores an uploaded cover under `site/assets/uploads/`, validates the site, commits the content and starts the existing GitHub Pages deployment. Drafts stay out of the public site.

Only issues created by the repository owner trigger publishing.
