- Sticky desktop sidebar and mobile share bar.
- Print / Save PDF on every story.
- Pull quotes and data modules are inserted INSIDE the article only when configured.
- Existing story tables automatically become searchable/sortable interactive tables with CSV download.
- Curated chart, table, timeline, map, explainer and pull-quote modules are supported.
- Previous/newer story navigation and topic-based related stories.
- Reading-progress bar only for long stories.
- About page uses a professional portrait and professional bio/recognition.
- Contact page includes a professional contact block and Send a News Tip block.
- Photography page is ready for curated work and links to the public Flickr archive.
- Email: arafat.mcj@yahoo.com

- SEO: canonical URLs, descriptions, Open Graph, Person/Article JSON-LD, sitemap.xml, robots.txt.
- RSS feed generated automatically.

STORY-SPECIFIC IMAGE WORKFLOW
V7 deliberately does NOT show a generic AR image when no story artwork exists.
For a custom editorial illustration:
1. Create an illustration based on the actual article.
2. Put the JPG/PNG source in site/assets/story-covers-src/ — for example:
   site/assets/story-covers-src/republic-strings.jpg
3. In site/data/story_enhancements.json add the exact Daily Star source URL:

"https://www.thedailystar.net/...": {
  "hero": {
    "base": "assets/story-covers/republic-strings",
    "alt": "Editorial illustration describing the story",
    "caption": "Original editorial illustration",
    "credit": "Arafat Rahaman portfolio"
  }
}

The workflow automatically creates WebP and AVIF versions.

INLINE EDITORIAL MODULES
Add an "inline" array to the same story entry. Each module uses after_paragraph.
Supported types: pullquote, explainer, timeline, chart, table, map.
Only add information supported by the article or a verified external source.

INTERACTIVE TABLES
Any real HTML table extracted from a Daily Star story is enhanced automatically:
search, column sorting, responsive scrolling and CSV download.
For data-heavy stories without an extracted table, add a verified table/chart in
story_enhancements.json.

PHOTOGRAPHY
site/data/photography.json is intentionally empty until photographs are curated.
Add selected photographs only when captions/credits are verified.

ANALYTICS
V7 includes an optional GoatCounter loader because GitHub Pages has no private
server-side analytics of its own. To activate it, create a GoatCounter site and
put only the site code in site/data/site_config.json:

"analytics": {
  "provider": "goatcounter",
  "site_code": "YOUR_CODE"
}

Leave site_code empty to load no analytics script at all.

CUSTOM DOMAIN LATER
Change site_url in site/data/site_config.json. The deployment build rewrites
canonical/static URLs and regenerates sitemap.xml/robots.txt/feed.xml.

DEPLOYMENT
After all V7 files are committed, do not manually click Run workflow repeatedly.
The push triggers the workflow automatically. V7 uses cancel-in-progress=true,
so a newer commit replaces an older running deployment instead of building a
long queue of stale runs.
